ПОДАРОЧНЫЙ САЙТ — ИНСТРУКЦИЯ

Внутри:
index.html — структура страницы
style.css — оформление и анимации
script.js — интерактивность и переходы
questions.json — вопросы, ветвление и пожелания
assets/character.png — персонаж с прозрачным фоном

ПРОСМОТР:
Распакуй архив и открой папку через Live Server в Visual Studio Code.
Или загрузи всю папку проекта на Netlify Drop: https://app.netlify.com/drop
Важно: не открывай index.html двойным кликом — браузер может заблокировать fetch для questions.json.

РЕДАКТИРОВАНИЕ:
В questions.json меняй тексты вопросов и варианты.
Поле next ведёт к следующему вопросу, result — к финальному пожеланию.
В index.html можно изменить текст love-note и подпись from.
